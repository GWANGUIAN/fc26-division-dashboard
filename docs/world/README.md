# 잔디동 월드 — 기획 문서 인덱스 & 세션 핸드오프

좌측 상단 플로팅 버튼 **"잔디동 월드 구경하기"** → 전체 화면 캔버스 **2D 도트 RPG**. 잔디동 멤버 11명 중 1명을 골라 마을을 돌아다니며 NPC와 대화하고 미션(기존 3D 카드·미니게임 + 월드 내 미션)을 풀어 **시들어가는 황금 잔디**를 살리는 게임이다. 엔딩 후에도 오락실·일일 미션·수집·카드 도감으로 계속 들어올 이유를 준다.

**현재 상태: S0~S5 완료, S6 코드 폴리시·릴리스 점검 완료(2026-09-19).** 오디오 연결·청크 캐시 상한·reduced-motion·크레딧/공지·문서가 실제 코드와 일치한다. 단, 배포 전 외부 오디오의 원본 출처·라이선스를 확인해 [07](07-audio.md)에 기록하고, 누락된 B14 `region-weed`를 제공하거나 지금의 필드 BGM 폴백을 승인해야 한다.

**S5 배포 후 `?worldDebug` 확인 체크리스트** (이번 세션에서는 브라우저 검증하지 않음)
1. 오락실 `interior:arcade` 5번 기계: 시작 → Space/↑ 점프·↓ 슬라이드 → 충돌 결과 → 재도전. Esc는 모달만 닫고 월드는 움직이지 않는지. 재접속 후 도감의 최고 거리·랭크가 유지되는지.
2. 엔딩 플래그를 설정하고 광장 게시판 (44,25): 날짜·3개 과제 확인 → 달성 → 스탬프 수령 → 같은 날 재수령 불가. KST 자정에 열린 게시판이 갱신되고 이전 과제 달성으로 새 날짜 보상을 받을 수 없는지.

**S2 배포 후 `?worldDebug` 확인 체크리스트** (사이트 주소 뒤에 `?worldDebug`. 좌측 패널이 디버그 도구, 빨강=충돌·청록=문·보라=조사·주황=NPC·연두=상호작용 프로브)
1. **타이틀 → 캐릭터 선택**: "새로 시작"에서 4×3 카드 11명이 뜨고 방향키/마우스로 움직인다. 고른 카드는 금색 프레임+위에서 통통 뛰는 공, 왼쪽에 큰 스탠딩·이름·포지션·집. Enter/"선택"으로 확정, Esc는 타이틀로(이때 기존 저장은 그대로). 네 가지 카드 프레임의 높이 차이가 눌려 보이지 않는지.
2. **프롤로그**: 임시 4줄이 타자기로 나오고 E/Enter/클릭으로 넘어감, Esc는 건너뜀. 끝나면 로딩 후 **내 집 실내**에서 위를 보고 서 있고 상단에 코치마크 "1/3".
3. **실내(19곳)**: 패널의 씬 목록으로 하나씩 들어가 그림이 화면에 맞는지(위아래 12px 잘림), 빨간 충돌 상자가 가구·벽과 맞는지, 캐릭터가 가구 위를 걷지 않는지, 문 아래로 나가면 페이드 후 집 앞마당. 어긋난 곳은 캔버스를 클릭해 뜨는 **px/tile 좌표를 복사**해 `interiors/<id>.json`을 고치면 된다. 조사 영역(보라)에 다가가 E로 문구가 뜨는지.
4. **마을**: 지면이 실제 텍스처로 깔리고 지구가 바뀔 때 하단에 토스트(지구 이름+색 점). 지구 경계(예: 중앙↔봄 정원, 중앙↔서리)가 디더로 부드럽게 섞이고 길·광장은 선명한지. 기본은 **시든 색**(조각 0개)이고 패널의 "색 복원 미리보기"를 100%로 올리면 초록·나무가 크로스페이드된다(시든 이미지가 없는 물·공업·제초 지면은 안 변함).
5. **소품·건물**: 나무 캐노피가 아래에서 올려다볼 때 머리를 덮고 줄기 뒤로 가면 가려진다, 건물 앞을 지나가면 건물 앞뒤 정렬이 맞다, 건물 벽은 전부 막히고 문 칸만 들어가진다(건물 정면을 따라 걷기만 해서는 안 들어감). 스타디움 문은 **남쪽 정면**.
6. **NPC**: 광장 잔디 할아버지에게 다가가면 머리 위 `E`(전방 28px 안), E로 임시 대사+선택지(↑↓/Enter), 대사 중 이동 정지·Esc로 닫기, 대사가 시작되면 NPC가 돌아본다. 꼬마·잔디냥·공돌이는 정해진 구역에서 배회하고 막히면 방향을 바꾼다. 멤버들은 집 앞마당에 서 있고 **내가 고른 멤버의 자리만 비어 있다**. 걷다가 캐릭터가 NPC를 뚫지 않는지.
7. **집/건물 입장·퇴장**: 문 칸 안으로 걸으면 페이드→실내→(아래 문)→페이드→집 앞. 클럽하우스 로비의 왼쪽 문(감독실)·오른쪽 문(트로피룸)·뒤 계단(오락실)과 편의점·스타디움. 실내 이미지가 처음 들어갈 때 잠깐 검은 화면이 길어지는지(지연 로드).

9. **Esc 순서**: 대사 → 코치마크 → (없으면) 월드 종료. 프롤로그·선택 화면에서는 각각 건너뛰기·타이틀로. *(S3부터: 플레이 중 아무것도 없을 때 Esc는 일시정지 메뉴를 연다. 월드 종료는 메뉴나 X.)*
10. **이어하기**: 프롤로그를 마친 뒤 닫았다 다시 열면 "이어하기"가 나오고 마지막 위치(실내면 실내)에서 시작. S1 때 만든 저장이 남은 브라우저에서는 "이어하기"가 안 나온다.
11. **소리·콘솔**: BGM/효과음 파일이 없으니 무음이 정상이고 콘솔에 에러가 없어야 한다(있다면 알려 주세요).
12. 기존 기능(미니게임·카드·테마 토글)은 평소와 동일.

**S3 배포 후 `?worldDebug` 확인 체크리스트** (사이트 주소 뒤에 `?worldDebug`. 좌측 패널 **"미션·진행"** 도구로 조각·플래그·미션 상태를 바꿔 볼 수 있고, 골(노랑)·체크포인트(초록)·줍는 것/공(하늘)·콘(주황) 오브젝트가 격자 위에 id와 함께 그려진다)
1. **HUD**: 좌상단에 조각 게이지(10칸)와 그 아래 트래커. 게이지의 채워진 칸이 프레임의 둥근 칸 위에 맞게 놓이는지(어긋나면 `world-mission.css`의 `--gauge-x/--gauge-pitch/--gauge-pip`). 트래커 글자가 잘리지 않는지, 보고 가능이면 깜빡이는지.
2. **튜토리얼(디버그 없이 처음부터)**: 새로 시작 → 프롤로그 → 집에서 나와 광장 할아버지에게 말 걸기 → 대화가 끝나면 "미션 완료: 마을 인사" 토스트, 트래커가 "감독님의 인사"로 바뀜 → 클럽하우스 로비 왼쪽 문의 감독실에서 우왁굳 머리 위 파란 `?` → 말 걸어 "받는다" → 머리 위가 회색 `…` → 카드 수납장(E)에서 카드 팝업이 뜨고 뒤집기가 끝나면 "목표 달성" 토스트 + 우왁굳 머리 위 **금색 `!`** → 보고하면 완료 + 메인 미션 10개(내가 고른 멤버 것은 빠짐)가 열림.
3. **Esc 스택**: 미니게임/카드 팝업 위에서 Esc는 팝업만 닫고(월드는 그대로), 메뉴의 설정/새로 시작 페이지에서는 한 단계 뒤로, 메뉴·미션 로그·대사 순으로 닫히고, 아무것도 없을 때 Esc는 **메뉴를 연다**(월드 종료 아님 — "월드 나가기"나 우상단 X). 코치마크가 있으면 첫 Esc가 그걸 건너뜀.
4. **일시정지 메뉴**: 설정에서 음악/효과음 켜기·볼륨(←→)이 바로 반영되고 다시 열어도 유지, "가이드 다시 보기"가 코치마크 1/3을 다시 띄움, "새로 시작"은 한 번 더 확인 후 캐릭터 선택으로 가며 Esc로 타이틀에 돌아가면 "이어하기"가 남아 있음.
5. **미션 로그(J)**: 진행/완료 탭(←→), 항목 선택(↑↓)과 오른쪽 상세(목표·의뢰인·장소·진행·보상), E로 트래커 지정(★), J/Esc로 닫힘. 재닌으로 시작하면 "서리 카드 뒤집기"가 없고 조각은 항상 10개.
6. **메인 미션 하나씩**(패널의 "튜토리얼 건너뛰기" 후 각 NPC에게 가서 수락):
   - **문모모·핑구·한결·재닌**: 클럽하우스 로비 안쪽 계단 → 오락실. 1번 합 10(≥60점), 2번 공 튀기기(≥20), 3번 프리킥(≥4골), 4번 카드 짝 맞추기(≤22턴)를 월드 안 모달로 플레이해 임계값을 넘기면 "목표 달성". 모자라면 안 넘어감. **대시보드에서 한 게임은 무관.** 모달을 닫으면 월드 음악이 돌아오고 Esc는 모달만 닫음.

   - **리냐·뽀린걸**: 감독실 카드 수납장 → 팝업 왼쪽 위 "다른 선수 카드 보기"로 그 멤버 선택 → 테마 선택에서 "조카의 스케치북"(리냐) / "90년대 고전 도트"(뽀린걸)를 고르면 달성(처음부터 그 테마로 나와도 인정).

   - **다시바**: 남서 콘 코스(4~18, 54~58). 시작 게이트를 지나면 타이머 시작, 콘(가운데 줄)을 **위/아래로 번갈아** 지나야 체크포인트가 카운트되고(직진하면 콘에 닿아 "+1초"가 뜨고 체크포인트는 안 지남), 도착 게이트에서 완료. 실패하면 시작 게이트를 다시 지나 재도전.

8. **패널 도구**: 조각 −/＋ 이 게이지·색에 바로 반영, "메인 전부 완료"로 색이 전체 복원(제초동 제외), "진행 초기화"로 처음 상태, 미션별 상태 지정("보고 가능"이면 `!`가 뜨고, "완료"는 보상이 한 번만 지급), 플래그 설정/해제(예: `main-open`), "타이머 취소"·"공 리셋". 색 복원 미리보기 슬라이더는 모든 지구를 한 값으로 덮어씀.
9. **집 안의 멤버**: 멤버 미션을 끝내면 그 멤버의 집 실내에도 본인이 나타남(내가 고른 멤버의 집은 그대로 비어 있음).
10. **이어하기와 기존 기능**: 진행 도중 닫았다 열면 미션·조각·수집품이 유지되고 진행 중이던 타이머만 사라짐(정상). 대시보드의 미니게임·카드·테마 토글은 평소와 동일, 콘솔에 에러 없음.

**S4 배포 후 `?worldDebug` 확인 체크리스트** (브라우저 일반 플레이는 하지 않고, 좌측 패널의 **결전 준비**·**스토리 초기화**·씬 이동·미션 상태 도구로 확인)
1. **대사 데이터**: 새 게임의 프롤로그 4줄·할아버지 튜토리얼·감독님 카드 수락/완료에 `(임시 대사)`가 없고, `?worldDebug`로 메인을 연 뒤 각 NPC의 제안→진행→보고→완료 후 idle을 확인한다. 미션 완료 뒤 해당 멤버 집에서는 `home[]`, `ending-seen` 뒤에는 `post[]`가 순환한다.
2. **진행도 이벤트**: 조각을 3/6/9로 맞춰 우왁굳에게 각각 한 번만 말하고, 10번째 조각을 얻는 순간 "최종 미션 생성" 토스트와 트래커의 "결전 준비", 우왁굳 머리 위 `?`, 화살표(외부→클럽하우스 입구→감독실 문→우왁굳)를 확인하고, 보고 뒤 **스타디움 문 열림** 토스트와 문 조건을 확인한다. 진행 중 미션은 트래커 화살표가 의뢰인이 아닌 실제 목표(오락실 기계·수집품 등)를 가리키는지도 함께 본다. 엔딩 뒤에는 이전 beat가 다시 나오지 않는다.
3. **스타디움**: 결전 준비 → 스타디움으로 이동. 심판의 `?`, 제초왕, 플레이어 자신을 뺀 관중 10명과 E 응원 대사가 보인다. 심판과 제초왕 어느 쪽에서 시작해도 컷 1과 1라운드 선택지가 같다.
4. **3연전 판정**: 월드가 연 모달에서만 R1 합10 80점, R2 공튀기기 20회, R3 카드 짝 맞추기 17턴 이하가 순서대로 인정되는지 확인한다. 실패는 같은 라운드 재도전, 통과 라운드는 유지, 대시보드에서 한 게임은 결전에 영향을 주지 않는다.
5. **엔딩 순서/Esc**: R3 보고 → 코어 정지·개화 배너(개화 중 Esc 무시) → 제초왕/감독 대사 → 단체샷 → 크레딧 순서. 단체샷 Esc/X는 크레딧으로, 크레딧 E/Enter/Esc/클릭은 스팅어로, 스팅어 E/Enter/Esc/클릭은 월드 복귀로 한 단계씩만 동작한다(S8).
6. **엔딩 후 맵**: `ending-seen`, `area-weed-open`, `weed-restored` 뒤 제초동 게이트 바리케이드·충돌이 사라지고 공장 문·제초 요원·스타디움 옆 제초왕이 도달 가능하다. 제초동 색이 복원되고, 트로피룸 액자는 단체샷을 연다.
7. **실내·조사**: 패널 씬 목록으로 실내 19곳을 열어 출입문/충돌/조사 문구를 확인한다. 스타디움·트로피룸처럼 상태별 `when` 문구가 전환되는지도 본다.
8. **지구 연출·오디오**: 존을 옮길 때 tint/파티클이 바뀌고 reduced-motion에서 줄어드는지, 선택적 앰비언스 파일이 없을 때 콘솔 오류 없이 무음으로 넘어가는지 확인한다.

3. 소리: BGM이 끊기고 밤 앰비언스(`frost-night`) → 컷4 공장 드론(`weed`) → 컷6 새벽(`field-day`)로 바뀌는지, 컷2·3의 시동음(`mower-rev`)과 컷5 스팅(`mission-ready`)이 어울리는지. 끝나고 스타디움 앰비언스가 돌아오는지. 소리가 어색하면 `stingerData.ts`의 `STINGER_CUES`만 고친다.
4. 건너뛰기: 크레딧에서 Esc/E → 스팅어로 가는지, 스팅어에서 Enter를 연타해도 컷이 한꺼번에 넘어가지 않는지(입장 애니메이션 중 입력 무시), Esc는 남은 컷을 모두 건너뛰어 월드 복귀·"제초동 구역의 문이 열렸어요" 토스트가 뜨는지. 스팅어 도중 월드를 닫고 다시 열었을 때 엔딩이 처음부터 다시 도는지.
5. reduced-motion에서 줌·틸트·팬·흔들림이 없고 페이드만 남는지. 창 크기를 바꿔도 이미지가 스테이지를 채우는지.

## S9 핸드오프 — ON AIR 전광판 (2026-09-20)

- [x] **전광판**: 멤버 11채의 문 위에 ON AIR 전광판. 방송 중이면 켜짐(붉은 글자·경광등·벽에 번지는 빛), 아니면 꺼짐. 클릭하면 **새 탭** — 켜짐은 생방송(`play.sooplive.com/<id>`), 꺼짐은 방송국(`www.sooplive.com/station/<id>`). 가로는 **입구 발판(`mat-door`) 가운데**, 세로는 "○○의 집" 이름표 위. 기획·조정 지점·확인 목록은 [15](15-onair-sign.md).
