# 잔디동 월드 — 기획 문서 인덱스 & 세션 핸드오프

좌측 상단 플로팅 버튼 **"잔디동 월드 구경하기"** → 전체 화면 캔버스 **2D 도트 RPG**. 잔디동 멤버 11명 중 1명을 골라 마을을 돌아다니며 NPC와 대화하고 미션(기존 3D 카드·미니게임 + 월드 내 미션)을 풀어 **시들어가는 황금 잔디**를 살리는 게임이다. 엔딩 후에도 오락실·일일 미션·수집·카드 도감으로 계속 들어올 이유를 준다.

**현재 상태: S0 기획 + S1 기반 구현 완료(2026-09-19).** 플로팅 버튼 → 로딩 → 타이틀 → 샌드박스 평지 이동/충돌까지 동작하고, 이미지 원본 151장이 전부 변환돼 저장소에 들어 있다. 다음 단계는 [아래 "다음에 할 일"](#다음에-할-일)을 본다.

**S1 배포 후 `?worldDebug` 확인 체크리스트** (사이트 주소 뒤에 `?worldDebug`)
1. 좌상단 버튼: 첫 방문엔 글로우+말풍선("잔디동 마을이 열렸어요!"), 클릭하면 사라지고 다시 안 나옴. 판 이미지 + 글자가 겹치지 않고, hover 시 밝아짐. 창 폭 1000~1900px에서 브랜드·공지 위젯이 버튼에 안 가려짐. 아래로 스크롤하면 원형 아이콘으로 축소되고 검색바가 안 가려짐. 폭 680px 이하에선 버튼 없음.
2. 로딩: 진행률 바가 차오르고 팁 문구가 바뀜, 최소 0.6초 표시 후 타이틀. 타이틀: 배경·로고·버튼 판 이미지, ↑↓ Enter로 선택. 저장이 있으면 "이어하기" 노출, "새로 시작"은 한 번 더 눌러야 지워짐.
3. 플레이: 재닌(실제 스프라이트)이 방향키/WASD로 이동, Shift로 달리기, 방향별 idle/걷기 프레임, 좌향은 반전. 한글 IME를 켠 채로도 WASD 이동. 방향키/Space로 뒤 페이지가 스크롤되지 않음.
4. 충돌: 초록 상자(발 충돌 박스)가 빨간 상자(나무 밑동·바위·벤치·울타리)에 막혀 슬라이드하고 모서리에 걸리지 않음. 노란 상자(이동 가능 영역) 밖으로 못 나감. 맵 가장자리에서 카메라가 멈춤(1280×960 맵). 콘솔에 에러 없음.
5. 선명도: 화면 배율이 `scale Nx device px`로 표시되고 도트가 번지지 않음(창 크기·브라우저 확대 변경 후에도). FPS ≈ 60.
6. 종료/재진입: Esc, 우상단 X, 타이틀의 "나가기" 모두 닫힘. 다시 열면 로딩부터 정상이고, "이어하기"로 마지막 위치에서 시작. 월드를 여는 동안 YouTube 음악이 멈췄다가 닫으면 (재생 중이었다면) 다시 재생.
7. 기존 기능(미니게임·카드·테마 토글)은 평소와 동일해야 함.

## 문서 갱신 규칙
- 규격·ID·파일명을 바꾸면 **01과 09를 먼저** 고치고 다른 문서를 맞춘다.
- 새 에셋이 필요해지면 09에 행을 추가하고 해당 프롬프트 문서(04~07)에 항목을 추가한다.
- 세션을 마칠 때 위 **핸드오프 체크리스트와 세션 로그**를 갱신한다.
- 결정이 바뀌면 결정 로그에 새 행을 추가(삭제하지 않고 "대체됨" 표기).
- 다른 문서 링크는 상대 경로, 코드 경로·라인은 백틱으로 표기(라인은 근사치이므로 구현 시 재확인).
