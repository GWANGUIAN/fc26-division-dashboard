# 잔디동 월드 — 기획 문서 인덱스 & 세션 핸드오프

좌측 상단 플로팅 버튼 **"잔디동 월드 구경하기"** → 전체 화면 캔버스 **2D 도트 RPG**. 잔디동 멤버 11명 중 1명을 골라 마을을 돌아다니며 NPC와 대화하고 미션(기존 3D 카드·미니게임 + 월드 내 미션)을 풀어 **시들어가는 황금 잔디**를 살리는 게임이다. 엔딩 후에도 오락실·일일 미션·수집·카드 도감으로 계속 들어올 이유를 준다.

**현재 상태: 기획 완료(S0). 코드는 아직 한 줄도 없음.** 다음 단계는 [아래 "다음에 할 일"](#다음에-할-일)을 본다.

## 문서 갱신 규칙
- 규격·ID·파일명을 바꾸면 **01과 09를 먼저** 고치고 다른 문서를 맞춘다.
- 새 에셋이 필요해지면 09에 행을 추가하고 해당 프롬프트 문서(04~07)에 항목을 추가한다.
- 세션을 마칠 때 위 **핸드오프 체크리스트와 세션 로그**를 갱신한다.
- 결정이 바뀌면 결정 로그에 새 행을 추가(삭제하지 않고 "대체됨" 표기).
- 다른 문서 링크는 상대 경로, 코드 경로·라인은 백틱으로 표기(라인은 근사치이므로 구현 시 재확인).
