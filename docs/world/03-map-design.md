# 03. 맵 설계 — 잔디동 월드

오버월드(80×60 타일)와 실내 19곳의 **구역·좌표·충돌·트리거·데이터 스키마**를 정한다. 규격은 [01](01-concept-and-architecture.md), 누가 어디에 있는지·무슨 미션인지는 [02](02-story-and-missions.md), 이미지 프롬프트는 [05](05-art-world.md).

## 1. 좌표계와 규칙

- 좌표는 **타일 (tx, ty)**, 원점은 좌상단, 1타일=32px. 픽셀 좌표는 `x = tx*32`, 엔티티 위치는 **발끝 중앙** 기준.
- 오버월드 `80×60`(2560×1920px). 가장자리 2타일은 두꺼운 숲/절벽 띠로 막는다(충돌).
- 좌표표의 사각형은 `x0–x1, y0–y1`(양끝 포함) 타일 범위. 아래 개략도는 **2×2타일=1글자** 축소본이라 오차가 있으며, **좌표표가 기준**이다.

- `props`는 `propDefs.ts`의 정의(`sprite`, 크기, `anchor`, `footprint`, `above` 스트립, `sortOffset`, `variantWithered`)를 참조한다. 소품 id는 [05 §소품 시트](05-art-world.md#2-소품-시트-11장)의 파일명과 동일하다.
- **무결성 테스트(vitest)**: 모든 `door.to.scene` 존재, 스폰이 충돌 밖, `npcs.cast` ∈ 캐스트, `props.prop` ∈ propDefs, `image` 참조 파일 존재, 모든 `pickup.id` 고유.

## 11. 충돌·정렬 규칙 요약

- 건물: 하단 `footprint`만 충돌, 상단(지붕·굴뚝)은 `above` 처리. 문 타일은 충돌 제외(트리거).
- 나무: 줄기 발치 16×12px만 충돌, 캐노피는 `above`.
- 울타리·물·벽은 사각형 충돌. 다리/데크는 충돌 없음 + 양옆 난간 충돌.
- y-sort 키: `sortY = footY + sortOffset`(대형 건물은 하단 y). 바닥 장식(decal)과 물 반사는 정렬 제외.
- NPC 위치가 플레이어 이동 경로를 완전히 막지 않도록 좁은 통로에는 `stay` NPC를 두지 않는다.

## 12. 볼거리·이스터에그 (아이디어 풀)

- 분수 조형: 축구공을 든 잔디 요정 동상, 3초마다 물줄기 리듬.
- 스타디움 외벽 전광판(코드): "잔디동 Let's Go!!" 스크롤(기존 LED 전광판 문구 재사용).
- 잔디냥이 플레이어를 잠깐 따라오다 멈춤, 공돌이는 플레이어가 공을 차면 쫓아감.
- 룬 탑 앞 "1황의 자리" 표지, 하치 언덕의 용볼 소문 표지판, 제초동 게이트의 "잔디 반입 금지" 경고문.
- 호수 밤(`z-frost`)에서 해파리 랜턴이 은은히 맥동, 다리 위에서만 들리는 물결 SFX.

- 숨은 문구: 콘솔 이스터에그는 기존 `main.tsx`의 "형 사랑해"와 중복되지 않게 별도 문구 사용.
