# Stadium Showcase assets

Both bundled GLB files are stored under `public/models/stadium-showcase/` and are used only by the lazy-loaded stadium showcase.

- `club-ground.glb` — [Assembled soccer club ground](https://3dassets.dev/assets/football-soccer-club-grounds-assembled-c-a701b13a-starter-scene), source `https://cdn.3dassets.dev/assets/19143/v1/model.glb`, CC0 1.0 Universal.
- `trophy-plinth.glb` — [Club trophy display plinth](https://3dassets.dev/assets/football-soccer-club-grounds-trophy-plinth-99e2c1de), source `https://cdn.3dassets.dev/assets/19142/v1/model.glb`, CC0 1.0 Universal.
- `soccer-ball.glb` — [Faceted panel soccer ball](https://3dassets.dev/assets/football-soccer-club-grounds-soccer-ball-118e3a67), source `https://cdn.3dassets.dev/assets/19091/v1/model.glb`, CC0 1.0 Universal.
- `scoreboard.glb` — [Club neutral elevated scoreboard](https://3dassets.dev/assets/football-soccer-club-grounds-scoreboard-e12a4ed5), source `https://cdn.3dassets.dev/assets/19133/v1/model.glb`, CC0 1.0 Universal.
- `ball-cart.glb` — [Wheeled open ball cart](https://3dassets.dev/assets/football-soccer-club-grounds-ball-cart-abb2cbb4), source `https://cdn.3dassets.dev/assets/19092/v1/model.glb`, CC0 1.0 Universal.
- `training-cone.glb` — [White band training cone](https://3dassets.dev/assets/football-soccer-club-grounds-training-cone-9635613a), source `https://cdn.3dassets.dev/assets/19096/v1/model.glb`, CC0 1.0 Universal.

Downloaded 2026-09-21. The source describes both files as self-contained GLB assets that need no extra decoder in Three.js.
