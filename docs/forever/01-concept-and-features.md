# 01. 컨셉과 기능

## 한 줄 컨셉

"11월, 잔디는 영원하다." — 피치 오른쪽 끝의 차원문을 통해 **잔디 포에버**(와우 포에버 패러디)로 들어가, 아제로스풍 마을에서 퀘스트를 받고 DING! 하고, 귀환석으로 피치에 돌아온다.

## 이름 규칙

| 항목 | 표기 |
| --- | --- |
| 서비스명 | **잔디 포에버** (Jandi Forever) |
| 게이트 프롬프트 | `잔디 포에버 입장` |
| 출시일 / D-day | **표시하지 않는다** (결정: 게이트 위 D-day, 출시일 상수 모두 제외) |

| 맵 이름 | 1차: **스톰피치 성문 광장** (연합/스톰윈드 톤) · 2차(옵션): **오그리 잔디마** (호드/오그리마 톤) |
| 길드 태그 | `<잔디동>` |

## 기능 목록 (우선순위)

**P0 — 필수**
1. 피치 우측 끝 게이트 (락커룸과 같은 y 라인), "잔디 포에버 입장" 프롬프트 (D-day 없음)
2. 와우식 로딩 화면 (로고, 진행 바, 팁)
3. `ForeverScene` — 스톰피치 성문 광장 1맵. 이동/충돌/펫 동행/y정렬
4. 존 진입 배너
5. 퀘스트 NPC + 노란 `!`/`?` 마크 + 수락/완료 팝업
6. 귀환석 캐스팅 바 → 피치로 복귀

**P1 — 와우 밈**
7. DING! 레벨업 연출
8. 리로이 잔킨스 NPC, 멀록 대사
9. 업적 토스트, 채팅 로그, 머리 위 이름표 + 길드 태그
10. 여관 · 우편함 · 그리핀 조련사, 액션바/경험치 바 장식 UI
11. 아이템 등급 색상 툴팁(기존 인벤토리 연동)

**P2 — 옵션**
12. 허수아비 슈팅 미니게임(데미지 숫자)
13. 2차 맵 오그리 잔디마, "역할 선택(수비/골키퍼/공격)" 게이트 연출, 영혼 상태 이스터에그

## 대사 초안 (와우 유저용 밈)

- 로딩 팁: "팁: 탱커가 없으면 던전은 시작되지 않습니다. 수비수 구함." / "팁: 골키퍼는 힐러가 아닙니다. 그래도 힐러입니다." / "팁: 킬 스틸은 반칙입니다. 오프사이드도 반칙입니다." / "팁: 죽으면 영혼 상태로 시체를 찾아야 합니다. 볼은 찾지 않아도 됩니다."
- 리로이 잔킨스: "잠깐만, 나 아직 스트레칭 안 했는데!" → 돌진 → "리로이이이 잔킨스!" / "적어도 난 치킨이 있잖아!"
- 멀록: "음르글글글!"
- 퀘스트 NPC: "이 잔디밭을 위협하는 토끼 5마리를 처치하게." (수락 시 사운드 + 팝업)
- 시스템 채팅: `[월드] 누군가: 잔디 포에버 언제 열려요?` (고정 문구 로테이션, 실제 채팅 아님)
- 여관주인: "휴식 상태입니다. 다음 골 경험치 +100%."

> 실존 인물 이름은 NPC 이름에 직접 쓰지 않는다(패러디 별명 사용). 전설 등급 NPC는 이름표 `투르카 (전설)`처럼 등급 색(주황)만 활용(실존 인물 이름은 쓰지 않는다). 우편함의 `우왁굳에게 온 편지`는 내용을 `~~~~`/`???`로 가려 둔 장식이다(02 §12).
