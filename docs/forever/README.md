# 잔디 포에버 (Jandi Forever) — 문서 지도

피치 화면 오른쪽 끝에 **"잔디 포에버 입장"** 게이트를 두고, 들어가면 와우 포에버(WoW Classic/Forever 감성)를 패러디한 맵으로 이동하는 기능이다. 축구게임(FC)을 "잔디"라고 부르는 밈과 와우의 상징(퀘스트 `!`, DING!, 귀환석, 리로이 젠킨스, 멀록)을 섞는다.

> **원칙: 문서가 코드보다 먼저다.** 각 세션은 아래 문서를 읽고 시작한다. 코드는 문서(특히 02)와 다르게 짜지 않고, 바꿔야 하면 문서를 먼저 고친다.

## 프로젝트 공통 규칙 (모든 세션)

- 작업 위치: `src/web/pitch/` (960x540 캔버스 게임). `src/web/world/` 이미지는 **레퍼런스로 쓰지 않는다** (`docs/pitch/04 §0`).
- 이미지 스타일은 기존 피치의 16-bit 아케이드 픽셀 아트. 이미지에는 **글자를 넣지 않는다**(로고 J2 제외). 텍스트는 코드가 Galmuri11로 그린다.
- 검증은 `pnpm test` + 타입체크만. **브라우저 수동 확인은 하지 않는다**(배포 후 사용자가 직접 확인).
- 셸 편집 주의: Bash heredoc의 아포스트로피 문제, Python의 CRLF 쓰기 문제 → Write 도구로 스크립트를 쓰고 Node로 실행.
- `public/sfxes/pitch-victory.mp3`(victory.mp3 계열)는 다른 기능 전용이므로 **절대 재사용하지 않는다**.
- 저작권: 블리자드 로고·공식 에셋·정확한 문양을 쓰지 않는다. "패러디풍"으로 새로 그린 것만 사용.
- 관련 기존 문서: `docs/pitch/03-screens-and-ui.md`(게이트), `docs/pitch/05-art-world-and-ui.md`(env 시트), `docs/pitch/09-image-generation-runbook.md`(#117 락커 게이트가 J1의 형제), `docs/pitch/12-title-logo-prompt.md`(J2 템플릿).
